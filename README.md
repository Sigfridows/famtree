# 🌳 FamTree

Sistema de gestión y visualización de árbol genealógico.

---

## 🚀 Guía de Contribución y Flujo de Trabajo (Git Workflow)

Para mantener el código limpio, estable y evitar conflictos de integración, todo el equipo debe seguir este flujo de trabajo.

### 🌿 Convención de Ramas
* **Rama principal:** `main` (Protegida. Queda prohibido hacer `push` directo).
* **Ramas de trabajo:** Todas las ramas deben ser cortas y nombrarse según la funcionalidad o tarea, **nunca por el nombre del desarrollador**.
  * **Buenas prácticas:** `feature/login-ui`, `feature/user-service`, `bugfix/fix-header-margin`
